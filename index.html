Sunny AI (Anthropic) Your API key lives only on this device — never in any file or code. Required for Sunny to work.
How to get your key:
1. Go to console.anthropic.com and sign in
2. Click API Keys in the left sidebar
3. Click Create Key, give it a name like "Sunday"
4. Copy the key (starts with sk-ant-) and paste above
5. Hit "Save & Connect" — Sunny will be live immediately

Database (Supabase) Stores your team, songs, roster, and conversations in the cloud. Syncs across devices.
How to get these:
1. Go to supabase.com and sign up (free)
2. Click "New Project" — give it a name, set a password, pick a region
3. Wait for it to spin up (~1 minute)
4. Go to Settings → API in the left sidebar
5. Copy the Project URL and paste it above
6. Copy the anon public key and paste it above
7. Go to SQL Editor, paste the schema from sunday-schema.sql, click Run
8. Hit "Connect" above — done!
WhatsApp Sunny can message your team — roster notifications, availability checks, blast messages.
One-time setup:
1. Sign up at twilio.com (free trial) and enable the WhatsApp Sandbox under Messaging → Try it out
2. In your terminal, run these three commands to set the secrets on the Worker:
npx wrangler secret put TWILIO_ACCOUNT_SID
npx wrangler secret put TWILIO_AUTH_TOKEN
npx wrangler secret put TWILIO_FROM For TWILIO_FROM use the sandbox number with the whatsapp: prefix, e.g. whatsapp:+14155238886

3. Each team member texts the sandbox join code to your Twilio number once to opt in
4. Add phone numbers to people in the People screen
5. Hit "Test connection" above — the dot should go green
